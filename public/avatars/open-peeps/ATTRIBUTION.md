# Open Peeps avatars

These 32 SVG avatars use the Open Peeps style through the DiceBear avatar API.

- Open Peeps: https://www.openpeeps.com/
- DiceBear Open Peeps collection: https://www.dicebear.com/styles/open-peeps/
- License: CC0 1.0 (public domain)

Each file uses a stable `orbit-avatar-NN` seed and a smile-only expression set so saved avatar keys render consistently and happily.
